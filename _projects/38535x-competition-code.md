The C++ codebase that runs my VEX V5 competition robot, written on PROS with LemLib. It covers the drivetrain tuning, odometry, a wall based position reset that uses four distance sensors to correct drift during a match, an anti jam routine for the intake, and an on screen autonomous selector.
