This is a narrow overhead panel from my homemade 737 cockpit that carries the ALT HORN CUTOUT control. I drew the outline, the mounting holes and the single round switch opening as a laser cut vector so the labeled face could be cut cleanly. The second design file is a larger companion plate with a big square cutout and a rounded opening, which supports the same overhead area.
